# FPE ChatGPT Plugin

Private skills-only plugin distributed through the ChatGPT plugin creator. It contains the FPE brand skill and bundled source references. No remote MCP endpoint or action tool is fabricated.

After creating the plugin, open the returned plugin URL and connect it. Creation in an account does not prove that the plugin is enabled in the current chat.

Skill instructions are shared with the Claude package; source code and tokens are bundled as references for consistent offline generation. The FPE logo is a separate rights-reserved asset.

## Brand icon

Both light and dark plugin and composer icons use the approved FPE logo geometry. Light uses black on white; dark uses white on black. These are generated from the three canonical `assets/brand/fpe-mark*.svg` files.
